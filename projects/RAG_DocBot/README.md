Developed state of the art project for building RAG (Retrieval-Augmented Generation) based chatbot which is a robust, AI-powered PDF document assistant (DocBot) leveraging the latest Large Language Machine Learning model, hosted on a secure, localized, and on-premises server setup. 
The DocBot streamline document question answering, and context-aware search functionalities, enhancing access to resources and operational efficiency for my organization.

Technology Stack:
1. AI Model: LLaMA 3.2 (Latest version: 3B).
2. Model Hosting: Ollama Server, localized and on-premises for enhanced data security.
3. Programming Language: Python
4. Database: Qdrant for vector storage and retrieval.
5. Web Framework: Streamlit for the frontend.
6. Containerization: Docker for easy deployment and isolation.
7. Network: Docker Compose for multi-container orchestration.

Key Benefits:
1.	Enhanced Efficiency: Rapid access to information and documentation, reducing time spent on manual searches.
2.	Data Security: On-premises setup ensures confidentiality and compliance with internal data security standards and minimizes external dependencies.
3. Centralized Access: Consolidates resources, making documents easily accessible to all users. (Will be done once GPU based Server is set up)
